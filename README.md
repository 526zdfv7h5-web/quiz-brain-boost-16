# Brainy Quiz Maker

Build a mobile-first web app called "Brain Train AI".

The purpose of the app is to allow students to upload a PDF of lecture notes, textbooks, or study materials and automatically generate quiz questions from the contents.

For the first version, create:

1. A clean, modern home page.

2. A prominent PDF upload area.

3. A difficulty selector with:

   - Easy

   - Medium

   - Hard

4. A question-count selector:

   - 5

   - 10

   - 20

   - 30

5. A "Generate Quiz" button.

6. A quiz page where generated multiple-choice questions will appear.

7. Each question should have four answer options (A, B, C, D).

8. A results page showing:

   - Score

   - Number correct

   - Number wrong

   - Percentage

9. Make the entire interface responsive and especially optimized for phones.

Use a simple, professional educational design. Do not add authentication, payments, databases, or unnecessary features yet.

For now, focus on creating the interface and navigation. We will connect PDF reading and AI question generation afterward.
